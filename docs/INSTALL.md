# 安装与使用

## 设备要求

- Android 11（API 30）或以上的 Android 手表。
- 主要适配圆形 OPPO Watch X（OWW231）；其他型号的排版和系统能力可能不同。
- 使用在线搜索、账号和音乐播放时需要可用网络。

## 安装

从 [最新 Release](https://github.com/yycun-ang/watchlisten/releases/latest) 下载 APK。请使用 Release 附件中的安装包；GitHub 自动生成的 Source code 压缩包是源码，不能直接安装。

有 ADB 环境时，在手表开启系统支持的调试连接，确认设备后执行：

```sh
adb devices
adb install -r WatchListen-0.10.0.apk
```

如果连接了多个设备，请使用 `adb -s <你的手表设备标识> install -r WatchListen-0.10.0.apk` 指定手表。安装文件名以下载到的实际 APK 为准。

升级使用覆盖安装。本版采用独立发布密钥，并携带本项目原测试证书到正式证书的签名轮换证明。已在 OWW231 / API 30 上完成从 **0.8.0 升级到 0.10.0**：没有卸载，应用 UID 和首次安装时间保持不变，原账号登录状态保留。

只有与该签名历史匹配的旧安装包才能按此方式迁移；其他来源或自行构建的包不能据此保证兼容。如果提示签名不兼容，先保留现有数据并提交问题，不要为尝试升级直接清除应用数据。卸载会删除手表中的导入音乐、关联歌词、偏好和本机记录；酷狗云端喜欢和歌单仍由酷狗账号保存。

Release 提供 SHA-256 校验文件，可核对下载包：

```powershell
Get-FileHash .\WatchListen-0.10.0.apk -Algorithm SHA256
```

```text

```

正式发布证书的 SHA-256 指纹：


包大小为 5,764,026 字节，`versionCode` 为 16。更多验证信息见 [发布验证](./VERIFICATION.md)。

## 首次打开与账号

首次打开，或隐私说明版本变化后，先阅读应用内的隐私与免责声明。明确同意后才启用联网。

在个人中心用手机酷狗扫描二维码，并在手机端自行确认授权。应用不要求输入酷狗密码。请不要把登录二维码或凭据发到公开反馈中。

首页头像、个人中心和歌曲爱心读取同一账号状态。“我喜欢”和云歌单来自酷狗账号，喜欢或移除以服务端读回确认。新建歌单请求超时后，可在管理页查询待确认结果；放弃记录前建议先查看手机酷狗，避免产生同名歌单。

取消喜欢或移出歌曲后，当前页面提供 60 秒撤销。撤销失败可点“重试撤销”；切换账号或有效期结束后，该次撤销不再可用。

## 播放与歌词

- 从搜索、云库或离线音乐点播后，进入同一个播放器。
- 在播放页向上滑动可打开歌词，歌曲列表与详情页保留来源返回。
- 播放控制页可管理队列、播放模式、音质偏好和睡眠定时。
- 实际音质及完整播放或试听状态以服务端结果为准。会员身份不代表所有歌曲、音质或地区均可完整播放。

## 手机传歌

1. 手机和手表连接同一个可互访的 Wi-Fi。
2. 在手表的离线音乐中打开“手机传歌”，手动开启接收。
3. 手机扫码或打开手表显示的局域网地址，输入手表上的 8 位验证码。
4. 选择自己有权使用的音频原文件，开始传输。页面显示逐首任务与已确认进度，可暂停或只重试失败项。

续传需要保留手机页面与当前手表会话。刷新页面需要重新选择文件；关闭传歌、更换网络或 15 分钟会话到期后，会清理未完成暂存。传歌默认关闭，不会在应用重启后自动开启。

如果同一 Wi-Fi 仍无法连接，检查路由器的访客网络或设备隔离设置，保持手表会话开启。连接信息包含局域网地址与临时验证码，不要公开分享。

## 离线文件与本地歌词

离线音乐的歌曲更多菜单提供文件格式、体积、原文件导出、LRC 关联和删除。导出会保存原始音频，不重新压缩。多选整理可一次移除多首导入文件；删除前会要求确认。

导入歌词时，先选定要关联的歌曲，再使用系统文件选择器选择 LRC 或文本。支持 UTF-8、UTF-16 和 GB18030。纯文本可浏览，但不生成虚假的同步时间；歌词不会按同名歌曲自动猜配。

系统文件选择器和语音识别取决于手表固件。若没有可用文件选择器，音频可通过手机传歌导入；本地 LRC 暂不支持网页传入。

## 手机投放（DLNA）

在手表“手机投放”中开启接收，然后在同一 Wi-Fi 下使用支持 DLNA 的手机播放器选择“腕上听”设备。手机可投放歌曲并控制播放、进度与音量，手表显示统一播放页。

酷狗手机版的投放入口可能随版本变化。该功能使用标准 DLNA，与酷狗手机连接电脑的 Play 功能不同；只接收可直接播放的音频流，不支持 DRM 加密内容或 HLS 播放列表。真实手机酷狗互联仍需更多设备验证。

DLNA 接收默认关闭。你可以随时断开当前手机或关闭接收；等待投放 10 分钟、暂停或停止 30 分钟后会自动关闭。请只在信任的局域网内开启。

## 问题反馈

在 [Issues](https://github.com/yycun-ang/watchlisten/issues) 中提供应用版本、手表型号、Android 版本、复现步骤与预期结果。需要诊断时，在“我的音乐 → 连接与播放诊断”主动导出并先检查文件内容；它只包含白名单状态，不自动上传。不要提交账号凭据、二维码、完整访问地址或原始音频文件。
