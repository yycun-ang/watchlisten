## OWW231 真机验证

在一台 **OPPO Watch X（OWW231 / API 30）** 上完成：

- 从 0.8.0 保留数据覆盖安装到 0.10.0，没有卸载；应用 UID 和首次安装时间保持不变。
- 用户自行阅读并确认隐私说明第 5 版后，原账号登录状态保留，酷狗云端“我喜欢”读取正常。
- 真实酷狗歌曲成功播放，媒体会话进入播放状态；暂停操作正常。
- 首页、四类搜索、诊断、关于和手机传歌入口显示正常。
- 连续返回两次分别回到上一层页面，没有直接跳回首页。
- 上述页面检查期间未发现应用致命异常。

页面与返回专项共 **9 项通过**；播放控件、媒体会话播放状态及暂停共 **3 项检查通过**。公开记录不包含设备序列号、真实账号、歌曲或原始设备日志。

## 兼容边界

- 真机结果来自一台 OWW231，不能覆盖所有型号、固件、网络与账号组合。
- 正式酷狗账号的云端增删改、VIP 专用账号与不同版权曲目、真实手机酷狗 DLNA 互联仍未完成全面联测。云端写入逻辑已有自动化测试，服务端兼容性仍需持续验证。
- 歌曲的完整播放、试听、地区和实际音质由服务端授权决定，应用不绕过相关限制。
- 系统文件选择器与语音识别依赖手表固件；本地 LRC 当前需要系统文件选择器。手机传歌与 DLNA 需要可互访的同一 Wi-Fi；DLNA 暂不支持 DRM 或 HLS。

如发现问题，请按 [反馈说明](./INSTALL.md#问题反馈) 提供版本、设备、系统及复现步骤，并遮挡账号、二维码和网络地址。
